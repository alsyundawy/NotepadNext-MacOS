## [0.15-03] - 2026-10-18

### 🎨 UI & Dialog Modernization / Modernisasi Antarmuka & Dialog

- 🇬🇧 **Find & Mark Single-Box Input Enforcement**: Streamlined Find/Replace dialog by enforcing single-box input for Find and Mark tabs, eliminating confusing duplicate text fields and ensuring seamless workflow.
- 🇮🇩 **Penegakan Input 1-Kotak untuk Tab Temukan & Tandai**: Menyederhanakan dialog Cari/Ganti dengan menerapkan input satu kotak untuk tab Temukan dan Tandai, menghilangkan kolom input duplikat yang membingungkan.
- 🇬🇧 **Preferences & Exit Toolbar Icons**: Restored high-visibility Preferences and Exit action icons across the main window toolbar for rapid access.
- 🇮🇩 **Ikon Bilah Alat Pengaturan & Keluar**: Mengembalikan ikon Pengaturan dan Keluar pada bilah alat jendela utama agar lebih mudah diakses.

### 🌐 Localization & Upstream Synchronization / Sinkronisasi Terjemahan & Upstream

- 🇬🇧 **Upstream Harmonization**: Absorbed upstream improvements from `dail8859/NotepadNext` (v0.15).
- 🇮🇩 **Harmonisasi Upstream**: Mengintegrasikan peningkatan terbaru dari upstream `dail8859/NotepadNext` (v0.15).
- 🇬🇧 **Indonesian Translation Refinements**: Refined terminology and grammar across all menus, dialogs, and notifications in Bahasa Indonesia (`id_ID`).
- 🇮🇩 **Penyempurnaan Terjemahan Bahasa Indonesia**: Menyempurnakan istilah dan tata bahasa di seluruh menu, dialog, dan pesan dalam Bahasa Indonesia (`id_ID`).
- 🇬🇧 **Local DMG Build & Verification**: Successfully built and cryptographically verified native macOS DMG (`NotepadNext-v0.15-03-x64.dmg`) locally with `hdiutil verify`.
- 🇮🇩 **Build & Verifikasi DMG Lokal**: Berhasil mengompilasi dan memverifikasi integritas berkas DMG macOS (`NotepadNext-v0.15-03-x64.dmg`) secara lokal dengan `hdiutil verify`.
